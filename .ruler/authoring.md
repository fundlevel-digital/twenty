# Agent configuration sources

Ruler owns the root rules in `.ruler/*.md`. Run `yarn ruler:apply` after changing them. This is a configuration utility; Twenty remains an Nx/Yarn monorepo.

Do not edit generated `CLAUDE.md` directly. The existing `AGENTS.md -> CLAUDE.md` alias gives Codex, Cursor, Pi and OpenCode the same rules. Only the Claude output is generated, so Ruler never writes through that alias or rewrites package-level instructions. Keep both source and generated root rules tracked.

MCP configuration stays under the repository's existing ownership. This setup does not manage `.mcp.json`, `.codex/config.toml`, `.claude/settings.json`, or other clients' connection settings.

Skills are canonical under `.agents/skills/<name>/SKILL.md`, following fundlevel-digital/mono. Claude and Pi use relative aliases under `.claude/skills/` and `.pi/skills/`. Skills are not generated by Ruler; do not duplicate their contents into agent instruction files.
